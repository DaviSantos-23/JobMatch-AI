# Regras de Negócio

## Critério de compatibilidade

Cada vaga recebe um Match Score baseado na compatibilidade entre:

- requisitos da vaga;
- conhecimentos técnicos;
- experiências;
- projetos;
- tecnologias;
- palavras-chave do currículo.

## Filtro de vagas

Vagas abaixo do percentual mínimo definido não são encaminhadas para adaptação.

## Currículo adaptado

O currículo adaptado deve:

- manter informações verdadeiras;
- destacar competências relevantes;
- utilizar palavras-chave presentes na vaga;
- priorizar projetos relacionados;
- não inventar experiências;
- não adicionar tecnologias que não façam parte do perfil.

## Armazenamento

Cada oportunidade aprovada deve registrar:

- nome da vaga;
- empresa;
- link;
- Match Score;
- lacunas identificadas;
- currículo adaptado.
