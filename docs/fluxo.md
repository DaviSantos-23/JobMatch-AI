# Fluxo da Automação

## 1. Disparo

O workflow é iniciado automaticamente através de um Schedule Trigger.

## 2. Busca de vagas

A API de busca de vagas é consultada utilizando os critérios definidos.

## 3. Extração

Os dados relevantes da vaga são extraídos e estruturados.

## 4. Filtragem

Vagas de fontes ou publishers indesejados são removidas.

## 5. Currículo base

O currículo principal é utilizado como referência para análise.

## 6. Match Score

Um agente de IA compara os requisitos da vaga com o perfil profissional.

## 7. Filtro

Somente vagas acima do percentual mínimo definido seguem para a próxima etapa.

## 8. Adaptação

A IA adapta o currículo para destacar experiências, competências e projetos relevantes.

## 9. Armazenamento

Os resultados são registrados no Google Sheets.
