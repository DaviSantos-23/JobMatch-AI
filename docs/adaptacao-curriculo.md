# Adaptação do Currículo

Após atingir o Match Score mínimo, a vaga é encaminhada para um segundo
agente de IA responsável pela personalização do currículo.

A adaptação considera:

- título da vaga;
- palavras-chave;
- tecnologias solicitadas;
- competências relevantes;
- projetos relacionados;
- requisitos técnicos.

O objetivo é aumentar a relevância do currículo para a oportunidade,
sem inventar experiências ou competências.
