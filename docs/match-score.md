# Match Score

O Match Score representa o nível de compatibilidade entre uma oportunidade
e o perfil profissional utilizado como referência.

A análise considera:

- conhecimentos técnicos;
- linguagens de programação;
- frameworks;
- ferramentas;
- experiência;
- projetos;
- requisitos da vaga;
- palavras-chave.

O resultado é representado por uma pontuação percentual.

Exemplo:

75% → boa compatibilidade

85% → alta compatibilidade

95% → excelente compatibilidade
